# 独立物品 FBX 与最终合并版的检查结果

比较源：`blender/物品重置.fbx`（Unity 默认导入）与最终 `Assets/酒狐合并.fbx`；实际提取还以 `Assets/main.unity` 中的组件和属性覆盖为准。

独立 FBX 确实不是可直接代替最终物品的数据源：

| 检查项 | 独立物品 FBX | 最终合并版中的物品部分 |
| --- | --- | --- |
| 顶点数 | 7,748 | 7,130 |
| 三角面 | 4,272 | 4,272 |
| 蒙皮骨骼 | 12 | 12 |
| 物品形态键 | 35 | 35 |
| 食品分段键 | 例如 I蜜渍苹果0–3 | I蜜渍苹果1–4 |
| 茶饮键名 | I建筑工茶饮0 | I建筑工茶饮 |
| I物理手杖 影响的顶点 | 390 | 380 |
| 物理手杖开 影响的顶点 | 146 | 128 |
| 手杖四个方向键，各自影响的顶点 | 34 | 24 |
| C烈焰蛋糕 影响的顶点 | 537 | 480 |
| C甜浆果 影响的顶点 | 648 | 596 |
| C紫颂果 影响的顶点 | 549 | 480 |
| C毒马铃薯 影响的顶点 | 481 | 432 |
| C金胡萝卜 影响的顶点 | 564 | 504 |
| C苹果 影响的顶点 | 566 | 492 |

这里的顶点数是 Unity 导入后包含 UV / 法线拆分的顶点数量；减少的顶点数不等同于减少相同数量的模型空间顶点或三角面。独立文件与合并文件的坐标系 / 导入变换也不同，不能直接交换 Mesh 后沿用全部旧绑定。

成品采用最终合并版的 RightHandLocator 及其子骨骼蒙皮岛，按实际骨骼权重选择顶点；只有三个顶点均属于物品的三角面才会被保留。提取时强制检查混合边界三角面为零，并检查所有物品形态键均不修改被剔除的身体顶点。随后逐项复制顶点、法线、切线、所有 UV 通道、颜色（若存在）、权重、bindpose 及每一帧物品形态键增量，不重新建模或重算物品外形。

保留的原 FX 层：旋转、扳机转换、物品、炮弹、手杖1、手杖2、声音；排除表情、颜色、饰品和 Action 控制器。不增加 FX 层或调试参数，食用接触器直接驱动原有 eating 参数。

正式轮盘直接移植 `主菜单.asset` 中的「物品」「食品」两项及各自子菜单；仅将参数名改为 MA 配件命名空间、将资源引用指向独立副本。原版名称、相对顺序、开关类型、参数值和图标一并保留。根入口的图标分别为原版扳手和蛋糕，扳机图标为原版 `item_wand.png`。没有在正式轮盘插入额外按钮。

表达参数按原版 DefaultExpressionParameters.asset 的物品部分设置：item/itrigger 分别映射为 WineFoxItems/Item（Int）和 WineFoxItems/TriggerInput（Bool），networkSynced=true、saved=true、defaultValue=0，共 9 bit。其余物品参数保持 Animator 内部参数，额外表达参数占用为零。原版随机 Driver 和接触器 localOnly=false 的行为保持不变。

从原版“空动画”剔除三个 `MRoot/AimDown` 缩放通道：它们服务于酒狐的前臂瞄准辅助物，不属于物品。其余物品动画路径全部转换为预制件相对路径，之后通过 MA 构建检查。

原始检查数据保留在工程根目录 `Artifacts/item-details.txt` 和 `Artifacts/source-inspection.txt`；提取与构建验证结果见同目录的报告文件。

MA 适配另作两项必要修改：原版依靠缩到约 1% 并藏入手中的几何，改为每个连通部分在未选择时收缩为零面积；对应形态键重新计算增量，100% 展开时保留最终合并版的外形（最大顶点误差约 2.33e-10 模型单位）。空手关闭渲染器，非发射状态炮弹缩放为零。加农炮去除原场景绝对约束偏移，改用 SDK 原生 FreezeToWorld，构建时放行本配件的 FX 骨骼动画，并将命中接触器延后 0.05 秒启用，避免射线结果更新前产生首帧误命中。物品切换可中断发射并立即隐藏炮弹。
